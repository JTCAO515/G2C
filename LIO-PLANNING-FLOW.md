# Lio unified planning flow (profile8 / data7)

Refs #835, #830, #822, PR836. Old profiles1–7 and their data formats remain unchanged.

- Registration `model.lio_intake.8` uses `LIO-planning-intake.8`; response discriminator `LIO-planning-intake.7`. The actual registered input and provider wire bind the same indexed schema SHA. No extra extraction call or second fee exit.
- `planning_request_index` identifies an actual traveler request rather than quoted/translated facts or sufficiency consultation. Facts alone do not authorize saving. The new flat sourced schema retains cumulative facts for every advisory intent. `publication_hold` binds a model-recognized refusal to an exact original source span; it can only deny publication, never grant it. `question_fields` records exactly which facts the model's natural reply asks about. It is reply metadata, never publication authority.
- A traveler-supplied destination and duration enter planning. Missing start date and party size are requested together; supplied dates/party facts are never defaulted or asked again. When the model asks precisely the missing facts, retain its reply bytes. Otherwise compose only the outstanding questions. An arrival date remains distinct from the trip's start; ask confirmation rather than adopting it.
- Existing conversation context stores source-bound city/start/duration/party facts. Ordinary consultations retain the pending plan but cannot populate its execution facts, including later model re-emission of quoted facts. A changed resolved destination persists its date-source boundary across further turns. A short continuation updates only supplied facts; explicit unknown/uncertain start or party clears the prior value. Before reuse, read the backing original MESSAGE in the same scope/conversation/generation, check its original bytes/hash/completed status and revalidate the source/value through the existing compiler. Older backing originals are retained beyond the recent eight-turn view; erased or inaccessible originals fail closed. A destination change does not inherit the old destination's dates.
- Original refusal, discussion-only, conditional, cancellation and previous withdrawn publication authority win over advisory model intent. A short date/party reply cannot restore a denied save. `不用保存`, `暂不保存`, `keep … unsaved` join the existing hold controls. Trip proposals/signatures, source-window checks, original NEEDS and full publication fences remain mandatory.
- Ordinary consultation requires no execution parameters and can answer without a Trip. A source/schema rejection remains UNKNOWN with only safe diagnostic code/hash/size, never silent repair or retry. Capability/persona questions retain the existing direct-answer path; the reported Chinese ability wording has a regression.

This is the backend intake contract only; LIO-message.2/timeline.2 are unchanged. No migration, role, invitation, key, quota or budget/hold reset. Rollback selects the prior reviewed image while preserving original actions, data and fees; UNKNOWN actions are never replayed. Source C0/pins must be regenerated against this source before future adapter integration. Actual A/C windows and nationwide16 are separate evidence.
