# Private simulator actor — #936

`LIO-simulator-actor.1` is a B-owned native RUN source. It is not a product
MESSAGE, reflection or Memory background job. It adds no HTTP route, identity,
SQL privilege, quota, provider, tool registration or fee ledger. A normal
MESSAGE worker cannot pick it up and a history producer cannot collect it.

The trusted B composition supplies `NativeActorHost` with its original C
`RuntimeAuthority`, current original account/profile, `RealTools`, a prepared
0700 canonical directory, the protected `ActorDutSource`, the episode's actual
last DUT MID, and a fixed `ActorSpecification`. The latter includes the actual
code/image/model descriptor. Construction is not runtime qualification: B must
first verify actual source/import/image bytes, current credentials, original
journal/suballocation, empty in-flight state, collector and an independent
formal C actor window. L basic QA and national16 windows grant no actor use.

## One original chain

```text
actual DUT receipt + current M projection + complete public history
  -> typed actor claim (same C owner, separate deterministic native RUN)
  -> model.simulator_actor.1 / original OperationStore / RegisteredExit
  -> same Meter account / MeteredDashScopeProvider / authorization journal
  -> fixed choice schema -> C render_choice -> ordinary next DUT input
```

`ActorDutSource.use()` holds the genuine current M projection outside actor RUN
transactions. It checks native receipt/generation/history, completed original
RUNs, erasure and actual displayed text. The full M/AUTH lifetime covers actor
send and publication; its callback cannot be retained. A copied transcript,
invented receipt or old callback is not a source permit. One DUT CID/generation
can bind only one profile/attempt slot. Actor IDs are stable for the original
DUT RUN, profile, attempt and round; pin or credential changes cannot mint a
replacement attempt.

`ActorClaim` reuses the existing canonical O_EXCL claim/admission/capability
mechanism with an explicitly different typed source. The native RUN binds only
`model.simulator_actor.1`; tools, planning, Trip/NEEDS publishers and Memory are
absent. It uses the original legacy RUN limits for this separate one-model RUN,
including on a v2 account. It does not consume or enlarge the DUT's native4
six-model planning allowance. All calls still count against C's original
account and shared financial/suballocation ceilings.

## Pins and observations

C's original dataset bytes, base `SIMULATOR_SYSTEM`, and canonical
`actor_output_schema()` are frozen at their accepted SHA256 constants. The
actual model is the existing configured endpoint/model, streamed JSON object,
thinking disabled and `min(1024, original max_output_tokens)` output. The
unchanged provider appends its existing synthetic/uncertainty clauses; archive
the **effective complete wire prompt** and JSON-object wire format separately
from C's base system and host choice-validation schema. The latter's canonical
hash is not a wire schema or dispatch permit.

`choose(messages)` returns only `answers`/`action`. Invalid paid output raises
`ActorChoiceInvalid` after retaining its actual completed native operation and
fees; it is never repaired or directly sent to the DUT. C's unchanged
`render_choice()` still enforces behavior, disclosure, round and direct-after
rules and releases the dataset's ordinary natural wording. A batch bridge maps
this expected error to C's `InputError`, and native `Unavailable` to C's
`HostUnavailable`; programming errors propagate and `finally` reads original
accounting. No operational failure is retried.

`ActorOriginals` reuses the existing operation/Meter/vendor/artifact checks over
the explicit actor claim/RUN source, without pretending it is a MESSAGE. Raw
input/wire/output reads reacquire the original DUT M frame. Fee/status metadata
retains current actor AUTH and original claim checks, including after the DUT
source is unavailable. Account revocation withholds both. There is no public
actor raw-output route.

The private producer sidecar must join actual profile/attempt/round and DUT
CID/generation/MID/RUN/input SHA/observer to the actor's native IDs, exact
logical input, wire/effective prompt/schema/parameters, output, Meter and vendor
fee originals. It must then bind validated choice and rendered-text digest to

locale: compare its actual native input and wire with the originals. Keep each
actor/DUT fee entry separate and sum every original operation, including
