# Intent-specific nationwide intake

#822 / #702. A distinct reg3 diagnostic correctly bound the current source,
but its discussion response was rejected: query was the exact city name while
quote was the containing original clause. It also generated unused NEEDS
parameters. Its original UNKNOWN and receipt remain unchanged.

New registration **model.lio_intake.4**, wire profile **LIO-planning-intake.4**
and response data **LIO-planning-intake.3** retain the latest original traveler
coordinate and its per-operation schema constant/SHA. They add explicit modes:

- `consult`, `discuss`, `cancel`: extraction=null, duration_days=null and
  field_sources={}. No execution parameters are generated, inferred or consumed.
  Original city evidence, intent, reply, current source index and envelope are
  still validated. The host branches before fields_for/register/save.
- `plan`, `save`: a full NEEDS-extraction.1 object remains required. All existing
  facts, original source/day, explicit event timezone, fixed/participant, owner,
  Memory, authority, signature and publication checks remain in place. Null is
  never interpreted as a valid plan or an implicit discussion fallback.

For city evidence, query is a nonblank exact contiguous substring of quote,
and quote is an exact contiguous substring of the indexed original traveler
turn. Example: query="杭州", quote="想去杭州玩两天" from that same original.
No normalization, concatenation, cross-turn evidence or proposed administrative
name may substitute for this original name span. Original Amap resolution,
translation confirmation, province negation and ambiguous-city checks remain.

Destination timezone is generated by the existing host from the confirmed
administrative source. The new model fields forbid destination_timezone; the
host does not accept and silently overwrite a model-supplied value. Explicit
arrival/departure/overseas and fixed-event timezone checks are unchanged.

Discussion/refusal/condition/cancellation never grants save authority. Existing
consultation Memory-candidate handling and explicit Remember remain unchanged;
null extraction creates no Memory activation capability. Previous data1/data2
and registrations/profiles1/2/3 stay available with their original semantics.
Old malformed outputs are neither converted nor repaired. The same single
model attempt, endpoint, model, limits, Meter and shared journal remain; no
second extraction step, retry or fallback is added.

The signed private-PG regression covers Chinese/English original discussion
and continuation, missing-details planning and continuation (zero NEEDS/Trip/
active Memory), plus the unchanged twelve complete city/language chains and
saved-only Memory identity. These are L0/L1 HTTP fixtures. New-source external
diagnostic, JT device, C nationwide and #32 evidence remain UNRUN until observed.
