# Explicit native simulator host (#936)

This is an opt-in composition of the original installed C profile/runner/renderer,
ordinary native DUT MESSAGE worker, independent native actor RUN, protected
original readers and the same registered model/fee exit. It adds no public route,
provider, account, quota or background executor. Source delivery is not a real
sixty-slot qualification or permission to call a provider.

```text
worker --simulator-manifest <owned manifest> [--start-simulator]
  ordinary run_once -> returned producer witness
  explicit start -> frozen C plan -> DUT -> actor -> unchanged C renderer -> DUT
    -> close original producers -> reconcile original operation/fee journal
```

The manifest flag is exclusive with runtime, App smoke and separate tool evidence
compositions, and is refused on API/migration entrypoints before loading secrets.
The flag alone constructs the guarded worker; only `--start-simulator` starts the
cohort. Default worker behavior remains unchanged. The actor and ordinary worker
serialize physical provider use on the same execution lock; the actor does not
hold that lock while waiting for an ordinary DUT reply.

## B-owned manifest

`G2C-native-simulator-host.1` contains exactly `version`, `window_id`, `mode`
(`legacy2` or `native4`), `runtime_card`, `actor_model`, `evidence_manifest`,
`results_directory`, `starts_at`, `ends_at`, `episode_seconds` and `identities`.

- `runtime_card` pins actual code SHA, image digest and configured DUT model;
  `actor_model` separately pins the original endpoint/model/parameters. C's
  dataset, system and output schema come from its installed frozen package.
- `identities` contains exactly the original ZH/EN subjects, owned 0600 token
  file paths and pinned canonical directory path/device/inode. The subjects
  must already belong to the configured Demo set; no identity is created.
- Results and canonical directories are existing owned 0700 directories. Results
  writes are exclusive, fsynced, 0600, without following symlinks; replacing the
  pinned results directory cannot discard the original cohort intent.
- Evidence is the existing scoped `.4` model/tool window, bound to these two
  original scopes, the same source and expiry. The host window is at most two
  hours and each episode at most 1800 seconds. Existing C standing windows,
  original AUTH, date, parent/line allowances and per-operation guards still
  apply. A future source or candidate label does not grant qualification.

B must first verify actual source/image/model, original account qualification,
remaining authorized C allowance, quote, empty in-flight state and exclusive
window. The manifest does not replace these facts. Credentials never belong in
argv, result metadata, repository or issue comments. Real activation and any
Hong Kong composition/configuration change remain B-only operations.

## Original lifecycle and stopping

A durable cohort intent and fixed deterministic slot/MID bindings are written
before new cohort work. Repeated start, an existing intent or a restarted host
cannot replay a prior paid attempt. `STOP_NEW.json`, changed manifest, expiry,
source/AUTH/native-action or accounting uncertainty stop new work. Worker
unavailability wakes the waiting original as UNKNOWN; it does not mint another
MID. Failed/UNKNOWN receipts and original fees remain in their original stores.
Programming errors are not converted into success or a financial verdict.

Each DUT reply requires a native ACK and a witness from the synchronous worker
return, not merely a completed RUN snapshot. Actor output/wire charge proofs are
captured while their original DUT frame is current. Later accounting rechecks
only permitted metadata; it never revives historical raw permission. Completion
requires original settled operations/financial receipts, all relevant Memory
history jobs completed/cancelled, no changed independent background-job graph,
unchanged prior journal rows, and an exact join of every newly added financial
attempt. A foreign or missing attempt yields UNKNOWN, not an observed subtotal.
The private report retains producer-return witnesses, Memory tails, inventory
hashes, individual operations and before/after ledger anchors. This certificate
is meaningful only for the separately qualified concrete worker composition;
calling a component or reading an invoice-free subtotal is not that qualification.

Known unpriced receipts retain their full conservative hold and an unknown token
estimate. Supplier payment remains unknown without the invoice. A known local
zero-cost visitor fact operation is still counted as its own native operation.

## Observations and evidence levels

The current observer reads actual protected public presentation. Missing accepted
profile, question census, Memory normalization or exploration ending remain
unavailable. An actually empty injected Memory packet can be recorded as empty;
missing bytes cannot. The unchanged evaluator's exploration bound remains a
measurement UNKNOWN, not a reason to change the old baseline protocol or claim
G2/G3 PASS/zero. Operational/accounting uncertainty stops the rest of the fixed
sixty slots; the cohort never replaces failed samples or changes 840 factors.

`runtime_simulator_host_pg.py` exercises two original ZH/EN slots over signed
private PostgreSQL, original native DUT/actor/next-DUT, actual protected artifacts,
returned worker witnesses and separate original fees. TCP is denied throughout;
HTTP transport is a local fixture. It explicitly selects the accepted HK scoped-ID
branch over its already constructed disposable Mac journal. It does not open an
HK journal/anchor, use cloud credentials, certify Memory recall, qualify native4,
or run the real sixty-slot baseline. The existing runtime_actor PG group runs
this fourth child alongside the three existing control programs.
