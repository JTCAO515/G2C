# JT 本地演练

从仓库根目录用已有的工作台回环 TLS 证书运行。脚本新建进程内队列、审计和案件状态。

    uv run --locked python -m jt.eval.drills --cert "$JT_WORKBENCH_CERT" --key "$JT_WORKBENCH_KEY" \
      --count 10 --minutes 30 --p0 1 --start-delay 180 --report jt-drill-report.json

用终端提示配置本次演练的本地管理员，然后在回环页面建立值班处理员和复核员账号。可增大准备秒数。值班处理员从待办进入对应案件并认领、推进和确认。P3 行程变更进入复核队列，由复核员打开并提交标注。其他四级走现有 playbook。

遇到「当前步骤仍需独立的客户同意」时，剧本将在读取拒绝审计后录入独立的合成客户同意。刷新当前案件页面后再重试。两个受保护步骤分别录入同意。

按 Ctrl-C 结束本次演练并收取 JSON。尚未注入、查看或完成的单会保留空值和卡点，退出码为 1。报告中的人工分钟数是首次审计查看到完成的历时，包含等待。P0 告警起点为本地队列接收，首次处理采用成功认领的审计时间。单纯查看页面不会被当作处理。报告里的证据可用于合成演练。
