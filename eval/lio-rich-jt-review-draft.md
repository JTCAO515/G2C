## 审阅顺序 / Review order

1. 硬约束与红线：锁定项、日期/日序、保存/修改/撤销、预约/付款/记忆声明。
2. 事实与来源：地点/菜名、开放日/预约条件、交通估算、过期或未知信息的表达。
3. 有实际隔离证据的留出项，随后是其余体验项。没有隔离证据就标 UNRUN，
   不把公开30题或已调提示词的样本改名为留出集，也不打开正式66例的封存题。

Review hard constraints and redlines first, then facts/provenance, then genuinely
isolated holdout items and other experience items. Public or previously tuned
examples are not holdouts. Missing isolation evidence stays UNRUN; this draft
does not authorize opening the sealed formal evaluation set.

## 逐条标准 / Criteria

| 项 / Item | JT 判定标准 / Decision standard |
|---|---|
| 硬约束 / Constraints | 原锁定项及其时段不变；日期与原问题日对应；撤销恢复原内容并保留历史。 / Locked items/times stay intact; dates follow their original question clock; undo restores the original content and keeps history. |
| G6 丰富度 / Richness | 普通日按节奏2/3/4景点+2餐；到达/离开日按§3.6例外单列；地点有高德ID或明确未确认，路线工具覆盖≥90%，住宿片区齐，已知开放冲突0。 / Check the selected pace and explicit edge-day exceptions, identified/unconfirmed places, ≥90% tool-backed routes, lodging area and zero known opening conflicts. |
| G7 理由 / Reasons | 引用因子确实存在且为known/memory；不把默认/推断说成用户说过。自由文案也不能曲解因子。违规算严重错误。 / Reasons must accurately use actual known/memory factors; defaults/inferences cannot become “you said”. Violations are severe errors. |
| G8 英文中文名 / Chinese names | 英文首提地点、菜名等附正确中文；罕见名称须有真实工具/事实依据，不猜。 / First English mentions carry correct Chinese names supported by actual sources; do not guess uncommon names. |
| §9.1 体验 / Voice | 先回答、长度档正确、合适具体下一步、未知时仍有可用部分、无系统口吻/多余格式；新4探索按#922问题组规则，不套旧单问句规则。 / Assess directness, applicable length, useful next step, honest useful uncertainty and presentation; native4 exploration follows #922. |
| >60 项长行程 / Over-capacity | 仅检查高德前明确拒绝、保原Trip、不截断/降节奏/拆Trip。单列，不计入G6成功或普通行程分母。 / Check explicit pre-tool refusal and preservation of the original Trip; no trimming, slower pace or split Trip. Report separately from G6. |

先看正文和行程前后对照，再看来源与代码结果。代码通过不能代替事实或行为证据；
模型评审只是预标。若原件缺失、事实未能核对或标准不清，标 UNKNOWN/待讨论，
不自动通过。任何红线 FAIL 单列，并阻止整体放行。

Read the answer and before/after itinerary first, then the sources and code
checks. Code/model judgments do not establish facts or committed effects. Mark
missing evidence or unclear standards UNKNOWN; any redline FAIL blocks release.
