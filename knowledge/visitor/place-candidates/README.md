# 广州景点与餐厅候选池（全部“待核实”）

本目录存放**尚未核实**的广州景点与餐厅候选，用于按批次扩大城市内容覆盖。JT 2026-11-18 在 H 会话布置：广州“能爬的都爬下来、能批量搜索的都搜索下来”，因此本批以**官方名录、榜单、公开页面批量提取**为主，优先数量与可检索性，不做逐条核实。

与正式内容的边界：

- 本目录任何记录都**不是已确认事实**，不得直接进入 Lio 回答、FACT wire、GitHub Pages 事实快照或任何消费者。
- 本目录与 `entries*/`、`names/`、`coverage/` 物理分开；不改变既有格式、来源白名单或消费者权限。
- 本目录与另外两个候选区分开维护：城市/场馆候选（`knowledge/visitor/candidates/`，PR #1195，`visitor-candidate.1`）与工具/App 候选（`knowledge/visitor/tool-candidates/`，PR #1197，`visitor-tool-candidate.1`）。本批需要“景点/餐厅”两类对象的名录字段，另立 `visitor-place-candidate.1`。
- 同一条目可能来自多个名录（如 A 级景区名录 + 米其林 + 商业榜单），**近似重复会保留**供后续查重；完全同名条目会合并来源。

## 格式 `visitor-place-candidate.1`

每个记录严格包含下列字段，不接受额外键：

| 字段 | 规则 |
|---|---|
| `format_version` | 固定 `visitor-place-candidate.1` |
| `id` | `place.<收集日期>.<城市键>.<category>.<slug>`；日期段= `collected_on`，城市/类别段必须与 `city`/`category` 一致；全批次唯一 |
| `city` | 城市键（本批为 `guangzhou`） |
| `category` | `attraction` 或 `restaurant` |
| `subcategory` | 非空中文子类，如 `5A景区`、`4A景区`、`3A景区`、`博物馆`、`公园`、`宗教场所`、`历史街区`、`城市地标`、`米其林二星`、`米其林一星`、`米其林必比登`、`米其林指南入选`、`广州老字号`、`美食街`、`小吃`、`粤菜` 等 |
| `name_zh` | 非空中文名（以来源原文为准） |
| `name_en` | 官方/页面给出的英文名；没有则 `null`，并在 `missing` 写“官方英文名待核实”，不自行翻译 |
| `district` | 所在区（如 `荔湾`、`番禺`）；来源没写则 `null` |
| `address` | 来源给出的地址；没有则 `null`，不猜 |
| `description_zh` | 非空中文概括，最多 300 字；批量名录行可用模板句，详细开放/预约信息待核实 |
| `tags` | 字符串数组，可空；如 `5A`、`红色旅游`、`米其林必比登`、`老字号`、`免费` 等来源可支持的内容 |
| `official_url` | 场馆/餐厅官方页或官方购票页；没有则 `null` |
| `attraction_info` | 景点必填：`{level, ticket_note, booking_note}`，未知项 `null`；餐厅必须为 `null` |
| `restaurant_info` | 餐厅必填：`{cuisine, reservation_note}`，未知项 `null`；景点必须为 `null` |
| `sources` | 非空数组；每项 `{name,url,type,language,published_on,valid_until}`；URL 优先 https，官方页仅有 http 时按原样记录；`published_on` 只在来源页明确标注时填写 |
| `collected_on` | 固定 `YYYY-MM-DD`，本批为 `2026-11-18`；不能晚于校验当天 |
| `status` | 固定 `待核实` |
| `missing` | 字符串数组，列出未知或缺少的关键信息（可空数组） |
| `notes` | `null` 或非空字符串，写适用范围、证据局限、名录口径 |
| `conflicts` | 字符串数组，记录不同来源的明显冲突（可空数组） |

来源类型：`official_government`（政府）、`official_venue`（场馆/景区官方）、`official_transport`（交通运营方）、`official_media`（官方媒体/政府新闻）、`commercial_platform`（商业平台，如米其林官网、携程、大众点评、本地宝）、`map_platform`（地图平台）、`other_public`（其他公开来源或机构身份未核实）。**来源类型只是如实标注，不代表已批准或已核实。**

## 本批采集方式与来源

- 优先批量名录：广州市文化广电旅游局《广州市A级景区名录》（2026-06 更新，共 114 家：5A 2、4A 37、3A 75）、广州市商务局《广州老字号名单》（2026-02-04，150 个品牌）、2026 广州深圳米其林指南（广州 117 家：二星 3、一星 17、必比登 52、指南入选 45）、博物馆/公园/宗教活动场所名录、政府与官方媒体文旅推荐。
- 次选商业榜单与公开页面（携程/Trip.com、本地宝、新浪/微信转载等），如实标为 `commercial_platform`，不作为官方政策或官方排名。
- 只读公开网页；未登录、未填表、未订餐、未购票、未调用接口/小程序、未使用付费服务；不保存原件/快照/运行日志。
- **未做全面查重、未统一纠错、未逐条复核**：缺失、冲突和近似重复均原样保留。

## 校验

在仓库根目录运行：

```sh
uv run --locked python -B -m unittest discover -s knowledge/visitor -p 'test_*.py' -v
uv run --locked python -B knowledge/visitor/validate_place_candidates.py knowledge/visitor/place-candidates/*.json
```

校验检查字段集合、id/日期/城市/类别耦合、子类与名称、景点/餐厅信息二选一、URL 形状、来源发布日期和重复项；任一文件失败退出 1。它不是内容正确性证明，也不联网。

- 景点：A 级景区覆盖 2 个 5A、34 个 4A、69 个 3A（官方名录共 114 家，本轮按市/区两级名录分批读取），另有公园 11、纪念馆 11、宗教活动场所/佛寺 11、博物馆 6、美术馆 2、城市地标/街区/夜游等约 50 条。

## 晋级为正式事实（后续轮次）

1. 人工复核：打开来源名录/场馆页，确认主体、地址、等级/菜系、开放与预约制度、英文名与时效；商业榜单不自动等同官方。
2. 查重：与既有 `entries*/`、`candidates/`、`tool-candidates/` 及本批同名/近名记录比对，合并或标注重复。
3. 来源批准：按 #702/#843 既有流程在 `SOURCES.md` 记录来源范围（本目录的收集不构成批准）。
4. 写入正式格式：按 `entries-v3/` 或后续版本落条目，附 `checked_on`/`expires_on`，走独立审查与精确 CI。
5. 晋级后从候选池删除或标注去向，避免同一内容两处维护。

本目录不保存抓取原件、网页快照或运行日志；来源只留 URL 和概括。
