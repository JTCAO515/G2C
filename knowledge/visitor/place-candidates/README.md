# 广州/深圳景点、餐厅、酒店与商店候选池（全部“待核实”）

本目录存放**尚未核实**的广州/深圳景点、餐厅、酒店与商店候选，用于按批次扩大城市内容覆盖。JT 2026-11-18 在 H 会话布置：广深地区“能爬的都爬下来、能批量搜索的都搜索下来”，并补酒店、外国游客可能使用的商店/店铺，同时把已有内容补上中英文名（官方英文名优先，没有则机翻并标注）。因此本目录以**官方名录、榜单、公开页面批量提取**为主，优先数量与可检索性，不做逐条核实。

与正式内容的边界：

- 本目录任何记录都**不是已确认事实**，不得直接进入 Lio 回答、FACT wire、GitHub Pages 事实快照或任何消费者。
- 本目录与 `entries*/`、`names/`、`coverage/` 物理分开；不改变既有格式、来源白名单或消费者权限。
- 本目录与另外两个候选区分开维护：城市/场馆候选（`knowledge/visitor/candidates/`，PR #1195，`visitor-candidate.1`）与工具/App 候选（`knowledge/visitor/tool-candidates/`，PR #1197，`visitor-tool-candidate.1`）。本目录使用独立格式 `visitor-place-candidate.2`，覆盖景点/餐厅/酒店/商店四类对象。
- 同一条目可能来自多个名录（如 A 级景区名录 + 米其林 + 商业榜单），**近似重复会保留**供后续查重；完全同名条目会合并来源。

## 格式 `visitor-place-candidate.2`

每个记录严格包含下列字段，不接受额外键：

| 字段 | 规则 |
|---|---|
| `format_version` | 固定 `visitor-place-candidate.2` |
| `id` | `place.<收集日期>.<城市键>.<category>.<slug>`；日期段= `collected_on`，城市/类别段必须与 `city`/`category` 一致；全批次唯一 |
| `city` | 城市键（本目录为 `guangzhou` 或 `shenzhen`） |
| `category` | `attraction`、`restaurant`、`hotel`、`shop` 之一 |
| `subcategory` | 非空中文子类，如 `5A景区`、`4A景区`、`3A景区`、`博物馆`、`公园`、`宗教场所`、`历史街区`、`城市地标`、`米其林二星`、`米其林一星`、`米其林必比登`、`米其林指南入选`、`广州老字号`、`美食街`、`小吃`、`粤菜` 等 |
| `name_zh` | 非空中文名（以来源原文为准） |
| `name_en` | 英文名；有官方英文名用官方名，没有则用机翻/音译；无法给出时 `null` 并在 `missing` 标明 |
| `name_en_source` | `official`（官方/来源页给出的英文名）或 `machine`（机器翻译/音译）；`name_en` 为 `null` 时必须为 `null` |
| `district` | 所在区（如 `荔湾`、`番禺`）；来源没写则 `null` |
| `address` | 来源给出的地址；没有则 `null`，不猜 |
| `description_zh` | 非空中文概括，最多 300 字；批量名录行可用模板句，详细开放/预约信息待核实 |
| `tags` | 字符串数组，可空；如 `5A`、`红色旅游`、`米其林必比登`、`老字号`、`免费` 等来源可支持的内容 |
| `official_url` | 场馆/餐厅官方页或官方购票页；没有则 `null` |
| `attraction_info` | 景点必填：`{level, ticket_note, booking_note}`，未知项 `null`；其他类别必须为 `null` |
| `restaurant_info` | 餐厅必填：`{cuisine, reservation_note}`，未知项 `null`；其他类别必须为 `null` |
| `hotel_info` | 酒店必填：`{stars, brand, note}`，未知项 `null`；其他类别必须为 `null` |
| `shop_info` | 商店必填：`{shop_type, goods}`，未知项 `null`；其他类别必须为 `null` |
| `sources` | 非空数组；每项 `{name,url,type,language,published_on,valid_until}`；URL 优先 https，官方页仅有 http 时按原样记录；`published_on` 只在来源页明确标注时填写 |
| `collected_on` | 固定 `YYYY-MM-DD`，本批为 `2026-11-18`；不能晚于校验当天 |
| `status` | 固定 `待核实` |
| `missing` | 字符串数组，列出未知或缺少的关键信息（可空数组） |
| `notes` | `null` 或非空字符串，写适用范围、证据局限、名录口径 |
| `conflicts` | 字符串数组，记录不同来源的明显冲突（可空数组） |

来源类型：`official_government`（政府）、`official_venue`（场馆/景区官方）、`official_transport`（交通运营方）、`official_media`（官方媒体/政府新闻）、`commercial_platform`（商业平台，如米其林官网、携程、大众点评、本地宝）、`map_platform`（地图平台）、`other_public`（其他公开来源或机构身份未核实）。**来源类型只是如实标注，不代表已批准或已核实。**

uv run --locked python -B -m unittest discover -s knowledge/visitor -p 'test_*.py' -v
