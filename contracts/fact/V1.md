# FACT@1.0 — synthetic data protocol

Owner B / #16, #306. New version under JT's 2026-10-30 authorization; the old
internal candidate, its examples, production-disabled acquisition and all frozen
versions stay intact. This version supports the explicit local synthetic profile.
It does not approve real sources. Authorized real-source integration must publish
an additive version/policy rather than relaxing this version's origin/flag checks.

## Executable interface

`cj_fact.contract_v1` exports `encode_query(Query)`,
`decode_query(bytes, evaluated_at=trusted_aware_time)`, `encode_result(Result, request_ref)`,
`encode_failure(Query, request_ref, outcome)` and `decode_result(bytes)`.
It reuses `parse_document`, `extract_structured_evidence` and `evaluate` as the only
source parser/applicability implementation. Model/request data cannot supply an
evaluation clock, source target, identity, tool registration or budget permission.

`FACT-query.1` has exactly `version`, `fact_key`, `region`, `dates`, `conditions`.
Dates have exactly `start`/`end` canonical ISO calendar dates, inclusive; conditions
are an object of unique string pairs. Keys/values and fact/region are nonblank,
at most 256 characters, with at most 32 conditions. DateRange/Query keep the legacy
domain's validation. No region, timezone, eligibility or current-date inference.
For the synthetic source, explicit `calendar_timezone=Asia/Shanghai` is necessary;
the source's date window is expressed in that calendar. Missing conditions remain
unknown; a different timezone is out of scope, never silently converted.

`FACT-result.1` has exactly `version`, `data_origin=synthetic`, `request_ref`, `query`,
`evaluated_at`, `outcome`, `status`, `original_value`, `summary_zh`, `summary_en`,
`sources`. Timestamps are `{iso8601, fold}` with explicit offset/microseconds and
fold 0/1, preserving the original offset/instant and fold. Output is <=131072 UTF8
bytes and <=16 sources. JSON is bounded, duplicate-free and finite; invalid UTF8,
surrogates, versions and unknown fields fail closed. A hash or label is not AUTH.

Each source has exactly evidence_id, fact_key, source_url, retrieved_at, media_type,
original_utf8_base64, original_sha256, value, declarations, status, reasons.
`value={text,start,end}` retains the exact original JSON literal and its Unicode
span; declarations retain optional regions, inclusive dates, conditions,
publication and expiry stamps. Missing declarations stay null. Base64 is canonical.
Only the exact HTTPS synthetic origin is accepted. The decoder reparses original
bytes with the existing parser and recomputes applicability; changed digests,
spans, declarations, summaries or verdicts are rejected. Data/association checks
do not prove source truth, owner, freshness, permission or Trip confirmation.

| outcome / status | Meaning |
|---|---|
| ok / supported | Explicit synthetic declarations cover this query at evaluated_at; exact original value retained |
| ok / unsupported_or_out_of_range | Region, date window or explicit condition differs; no extrapolation |
| ok / expired | Original evaluation is at/beyond the declared expiry |
| ok / conflicting | Applicable original values differ; none selected |
| ok / unknown | Missing applicability/freshness/condition; no precise value invented |
| no_results / unknown | No applicable code-owned synthetic source is registered |
| rate_limited, invalid_response, source_failure / unknown | Failure with separate bilingual status, no source body or invented value |

An actual acquisition timeout/unknown completion returns no successful result:
the registered host retains the original exposure and makes RUN unknown. No
automatic retry, new attempt/period, refund or empty-success substitution occurs.
Stored status applies to the explicit **original evaluated_at**. Reading it later
does not refresh the source or authorize a new query; consumers must display its
times/expiry and re-evaluate current applicability through an authorized path.

Original text/negation/date/currency/conditions stay visible. Bilingual summaries
describe applicability only, never an official translation, real forecast or
eligibility decision. Source instructions/metadata remain data. The fixed
[v1 examples](v1-examples.json) are generated synthetic fixtures, not recordings.

## Scope and rollout

The local producer has code-owned weather/entry_notice scenarios, synthetic-city,
a two-day synthetic test window and explicit source timezone. The window and
limits are test values, not production policy or real forecast horizon. Unknown
source keys stay unknown. Real `RestrictedAcquisition.fetch` remains closed.
The [host](TOOL-HOST-V1.md) performs all dispatch through canonical AUTH/RUN/Meter.
The codec itself never dispatches, persists, settles, edits Memory or confirms Trip.
App/CJ014 consumption and real sources retain their own acceptance; rolling back
stops new producers while retaining original consumers/operations/ledger records.
