## 分离的状态与规则

| 情形 | 中文 / English 状态意图 | 必须保持的边界 |
|---|---|---|
| 注册被受理 | 请完成邮箱验证 / Please verify your email | 不等于邮件已送达或用户已获业务权限；无需 JT 预创建账号 |
| 邮箱未验证 | 邮箱尚未验证 / Email not verified | 已邀请也不能据客户端标志绕过验证；允许进入必要账号验证/恢复流程 |
| 邮箱验证状态未知 | 暂时无法确认邮箱验证状态 / Unable to confirm email verification | 不当作未验证或账号无效，不派发模型 |
| 已验证但未受邀 | 当前账号尚无内测资格 / This account does not have beta access yet | 保留有效身份，阻止受限业务/模型；隐藏按钮不是门禁 |
| 资格查询未知 | 暂时无法确认内测资格 / Unable to confirm beta access | 不默认为已受邀，也不假报明确拒绝 |
| 登录被拒绝 | 无法登录，请检查登录信息 / Unable to sign in. Check your sign-in details | 不泄露邮箱是否存在；不把本次登录拒绝扩为其他既有会话失效 |
| 当前会话权威失效 | 登录已失效，请重新登录 / Your session is no longer valid. Sign in again. | 仅当前绑定的可信结果可清除当前会话/显示 |
| 找回请求被受理 | 若此邮箱符合条件，将收到恢复说明 / If this email is eligible, recovery instructions will be sent | 不证明账号存在、邮件送达或密码已改；避免账号枚举 |
| 验证/恢复链接无效或过期 | 此链接无法使用 / This link is no longer valid | 与当前会话失效分开；不能据失效链接登出另一账号 |
| 密码修改已确认 | 密码已更新，请重新登录 / Password updated. Please sign in again. | 重新核身份、邮箱与资格；不承诺全设备撤销，不自动启动模型 |
| 网络未知 | 结果尚未确认 / The outcome is not confirmed | 保留已有凭据；不假报已注册/邮件已发/密码已改或凭据无效 |
| 用户取消 | 已取消本次操作 / This operation was cancelled | 仅关闭本地流程并失效回调；不声称撤销已提交注册/邮件/密码修改 |

这些是语义/双语文案草案，不是 HTTP code 或 provider 错误枚举。实际 SDK 错误到
BASE 统一错误的映射仍由 CJ005/CJ007 固定；不伪造 request_id。

服务端依次核可信新 CJ 身份/会话、邮箱验证状态、独立邀请资格、资源归属；
在模型派发及有权威副作用的边界重查。邀请管理者已确定为 JT，但名单存储、
验证后邮箱与 principal 的绑定规则、邮箱变更处理、撤销传播和管理入口仍待定义。
不把客户端 email/owner/invited、恢复成功或注册成功当作邀请依据；不默认自动邀请。
既有草案对受限业务的服务端门禁保持，账号注册/验证/恢复入口不能被邀请门禁堵死。

## 自助注册、恢复与取消的实现接缝

- 通过选定官方 SDK/安全输入界面完成密码流程；不在聊天收密码，不由本模型代收。
  验证邮箱成功仅是重验输入；密码更改后重新登录，旧会话是否撤销须以实际服务端
  结果核定。恢复凭据仅授权指定恢复动作，不能直接授予旅行/模型业务权限。
- 注册、验证回调、恢复链接、密码修改与登录是不同操作上下文；未来 host 捕获
  原流程/实例/账号代次和 UI token。取消或替换流程后，原回调不得改变当前会话。
  确认链接不能盲目登录到当前另一账号；跨设备/重启链接须重新建立可信验证上下文。
- 取消只失效该流程绑定；若取消的是新登录生命周期，恢复匿名/未验证展示，
  不恢复旧私有数据；取消找回流程不自动登出既有有效会话。原 model 的 logout
  不能直接充当所有取消操作。实际 host 回调绑定与取消实现仍 UNRUN。
- 注册/发邮件/改密码已发出而响应未知时，不盲重发、不新建第二账号、不报回滚。
  先用所选 SDK 支持的安全状态查询/恢复步骤对账；如无法确定，保持 unknown 并
  给显式恢复路径。重发验证/恢复邮件的冷却、次数与费用规则待定，不能自动无限重试。
- 密码、邮件内 token、完整回调 URL 不入普通日志/模型/契约样例。回调严格匹配
  获批环境/应用、用途及可信 SDK 校验结果；链接域名/路径尚未选定，不猜默认地址。
