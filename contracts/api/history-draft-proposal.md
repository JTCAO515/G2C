## Draft unknown / integrity and BASE mapping (proposal)

Draft save never creates message/receipt/run/delivery. Same text is not an action identity: unknown save retains original id/generation/expected_revision/bytes, then reads the original draft/revision; matching content or revision alone does not prove which writer committed. No idempotency journal or automatic retry/force-overwrite is invented. Stale expected_revision InputConflict is409 failed/do_not_retry, not a blind overwrite. No DELETE/clear-on-empty API; empty UTF8 is an explicit saved draft.

All existing receive/query semantics unchanged. Reuse401 invalid identity,403 generic denied, entry/transaction-entry UNKNOWN503 unknown/retry_safe_read; commit/return uncertain effects and CommitUnknown prioritize503 unknown/reconcile_original. For draft unknown, reconcile_original means original draft/version read, not message receipt lookup. Invalid query/body/UTF8400; request byte bounds413; read output cap413/retry_safe_read; postcommit draft output/projection failure503 unknown/reconcile_original; wrong media415. ResyncRequired and authenticated codec invalid/expired/wrong binding →409 `HISTORY_RESYNC_REQUIRED`, failed/retry_safe_read (new first-page safe read, never write retry). Codec/TTL/host dependency absent/unavailable →503 unknown/retry_safe_read. Domain Unavailable for foreign/missing/inactive/stale context remains generic503 (no existence/ownership disclosure), never null/empty private history. No token/principal/reason/body leaked in BASE errors.
