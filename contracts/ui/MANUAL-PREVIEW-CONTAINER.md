# CJ006 selected formal Trip → local manual preview

The Trip detail screen offers Edit a local draft. Its synchronous action freezes the current TripContainerAction and calls the Trip client's public prepareDetailSnapshot before Task. The async step performs the actual generated formal getTrip; only its closed AcceptedTripDetailSnapshot can construct the public PreviewEditor. A displayed/list TripRecord, proposal, claimed version, arbitrary JSON or fresh binding cannot stand in for that accepted source.

The root may add ManualPreviewResources to the existing TripContainerBinding: explicit MessageEndpoint limits, existing trusted TripCredentialCallback and positive finite preview request/resource timeouts. Nothing is defaulted from old accounts, a device cache, JWT or user field. The default host creates the real public editor using its explicit readonly timeout initializer; the client constructs the narrowly scoped shared NoRedirectTransport per original work/source/session/revision. All other write-shaped requests remain disabled. No save/confirmation/lock or feasibility authority is supplied.

## Original lifetime and source ownership

Selection/account/environment changes synchronously retire the current editor; Trip selection including ABA also retires the canonical client's detail snapshots. Ordinary current-detail refresh retires the editor before preparing another source. Public Trip preparation may invoke a host callback, so the existing reserve step rechecks the original action after preparation before minting host work ownership.

Manual source-read work retains original binding/presentation/session operation and epoch. Source GET is one-use; duplicate callers cannot release busy. A view/foreground departure detaches and cancels only the original manual read after clearing its bookkeeping. Its late return cannot strand the host or overwrite a newer read/editor. New source construction and final display checks are followed by callback-free original host epoch/binding/session/foreground checks. Any unpublished stale candidate is retired locally; no stale cleanup retires a newer global Trip source or editor.

Every entry has its own UI token. Old dismiss/disappear events can retire only that entry. Returning from a departed detail screen cannot open a late editor. The sheet's discard action checks its original token, and interactive dismissal is disabled: Close confirms discarding nonempty local intent. A failed source check is not treated as an empty draft. Identity/background retirement still clears private UI without waiting for a confirmation. Language changes retain the same current editor.

## Preview and user intent

The public ManualPreviewView owns title/item selection, supported text/title/order edits, synchronous preparePreview before Task, preview state and the server's returned diff. The client reserves preparation ownership before callbacks, so a nested newer preparation with unchanged draft revision survives an older discarded caller. The shared readonly capability rejects every ordinary Host header, including same-origin values; baseURL remains the sole authority input. The shell does not implement a patch engine or manufacture diff entries. Only LOCAL/UNKNOWN-protection/can_save=false results validated by the domain client are displayed. There is no save button, action-confirmation request, lock edit, day/time model or automatic Trip refresh/rebase.

409/unavailable/unknown/invalid response retains the original draft and base version. Opening/closing does not automatically save or resend. Selecting a new base is an explicit action after retaining/reviewing or confirming discard of the local intent; the current sheet offers no silent refresh workflow. Cancel preview stops result use while cooperative transport may finish; source/revision checks reject its obsolete result. Root resource activation, server ownership and real account/endpoint remain separate gates.

CJShell tests use a module-internal editor factory only to run the actual closed Trip GET → PreviewEditor → exact shared readonly transport with a non-network interceptor. Production's public initializer always uses the actual public editor timeout initializer, with no alternate transport flag or injected accepted handle. A legacy generic NoRedirectTransport still rejects POST and keeps the draft unavailable. Local tests do not prove real networking, App rendering or complete Issue22/I acceptance.
