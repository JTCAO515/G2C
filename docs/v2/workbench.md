# JT Agent 工作台规格

本地中文网页，桌面优先，以宽度 ≥1280 px 验收。#1707 交付账号与安全边界，#1708 交付队列及信号复核。案件详情的步骤推进和揭示在阶段 2 演练。

## 角色与权限

| 角色 | 可见 | 可操作 |
| --- | --- | --- |
| 值班处理员 | 当前待办、脱敏信号、分配给自己的案件和 AI 草稿 | 核认告警、认领待办。阶段 2 按 playbook 处理已分配案件、确认或驳回草稿，并为当前步骤申请揭示。 |
| 复核员 | 待复核信号、脱敏片段、规则和模型证据、标注历史 | 标注与导出脱敏评测数据。 |
| 管理员 | 员工账号、角色状态、运维审计的必要元数据 | 创建、停用账号、分配角色、解除锁定以及授权重绑 TOTP。后台管理权本身不授予案件处理、揭示或标注权限。 |

所有访问由服务端按角色、对象范围及当前步骤授权。直接访问页面或接口与点击按钮执行同一权限检查。授权查看业务内容及揭示须记入审计。

## 页面与线框

| 页面 | 桌面布局与操作 |
| --- | --- |
| 登录 | 居中登录卡片依次收账号密码、TOTP。管理员建号，首次绑定页只在有效的账号设置流程内展示绑定资料。失败文案不给出账号是否存在。 |
| 待办队列 | 顶部显示 P0 告警横幅，左侧为分类和状态筛选，中间为列表，右侧打开信号详情。列表按 P0→P4，再按响应截止时间升序，最后按发现时间升序和内部信号 ID 稳定排序。显示级别、类别、状态、截止时间和已有关联的 `case_id`。 |
| 信号详情 | 侧栏上部显示级别、类目和发现时间，中部显示脱敏片段、规则命中、模型输出与置信度及各版本。复核区填写真实级别、误报、漏报和备注，记录提交人及时间，可导出脱敏评测样本。阶段 1 没有关联案件时显示「未建单」。 |
| 案件详情 | 顶部显示 `case_id` 和状态，左侧为已定版本的 playbook 步骤，中间为当前步骤与 AI 草稿，右侧为人工确认、驳回及在白名单内的揭示申请。涉及花钱或正式行程的步骤要显示客户同意门槛，工作人员确认不能代替。 |
| 审计日志 | 管理员按时间、员工账号、操作和结果筛选，按时间倒序读记录，详情只呈现必要元数据。 |
| 账号管理 | 管理员通过列表查看账号、角色及状态，从对话框完成创建、停用、解锁或 TOTP 重绑。 |

响应时限采用 ADR-0005 内部值班目标。以发现时间的北京时间判定昼夜，08:00（含）至 22:00（不含）加 5 分钟，其余加 20 分钟。P0 仍即时告警。

## 安全

- 员工使用独立账号、scrypt 密码哈希和 TOTP 双因素（RFC 6238）。管理员创建账号，入口实行服务端限速和连续失败锁定。密码与 TOTP 密钥不进入日志、队列/API 错误或日常页面，TOTP 绑定资料仅交账号本人完成绑定。
- 服务端执行短时效会话、空闲超时和登出撤销，Cookie 设置 `HttpOnly`、`Secure` 与 `SameSite=Strict`。确认、标注、揭示和账号管理等状态修改校验 CSRF。会话过期及跨角色请求拒绝。
- 工作台默认打码，业务页面只显示面向员工的 `case_id`，隐藏用户 UUID 及私有来源引用。揭示只面向授权处理员和当前步骤声明的字段，提交理由后由服务端核验，授予限时访问并追加审计。关闭案件后授权立即失效，护照号默认不可揭示。
- 审计只追加，由服务端记录登录成功或失败、查看、标注、揭示、人工决策与账号管理。元数据包含时间、操作者、操作、对象的内部可审计引用、结果及必要理由。禁止写入密码、TOTP 密钥、会话凭据、原文或揭示值。无修改或删除接口。
- 样式、脚本与声音使用本地资源。页面不加载第三方 CDN 或外部脚本。

## 告警与存储

- 演练期 P0 告警仅在当前工作台显示横幅、播放本地声音和使用已获浏览器许可的本地通知。声音或通知不可用时横幅仍显示。夜间 P0 覆盖和值班安排在阶段 3 前决定。
- 阶段 1–2 只用本地合成数据。阶段 3 如获批并实际提供真实存储，按 [ADR-0009 第 6 条](../adr/0009-jt-agent-contract-reservation.md#6-存储登记与清理修正共识稿的做法) 在同一 PR 登记 storage-registry 并交付清理钩子，包含保留期、主体绑定、敏感字段和备份恢复边界。此前不登记占位存储。
