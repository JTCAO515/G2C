# V2a 影子模式规格：在真实流量上验证识别

状态为阶段 4 规格，真实接入仍待授权。阶段 1–2 先以[工作台](workbench.md)和[合成数据](signal-contract.md#合成事件)完成本地演练。阶段与边界见 [JT Agent V2](README.md)、[ADR-0005](../adr/0005-proactive-fulfillment.md) 和 [ADR-0009](../adr/0009-jt-agent-contract-reservation.md)。

## 目标

真实流量阶段只验证识别与人工复核。用同一标注集评估候选模型和规则，得到各类信号的精确率、召回率、阈值和每单人工分钟数初估，作为扩大真实处理范围的依据。P0 按既有应急边界单独处理。

## 范围

1. **事件接入**。按稳定 ID 消费 CJ 事件引用，从只读白名单视图取必要上下文。JT Agent 在对话关键路径之外，故障不影响 CJ 可用性和延迟。
2. **本地脱敏**。将姓名、护照号、电话、邮箱、精确位置替换为类型化占位符。规则写版本并运行回归测试。外发前检查内容、授权与候选厂商合规。
3. **识别**。确定性规则持续运行，独立识别 P0。模型按[共用契约](signal-contract.md)给出类型、级别与置信度建议。千问约束输出与 TypeSafe Jev 都是候选，按评测选定。
4. **证据**。Signal 留来源引用、规则命中、模型输出、最终级别与类型、规则及脱敏版本。运行评测分开记各候选版本、耗时、费用、失败和未知；复核标注留在工作台。
5. **复核**。工作台每日抽样，P0、P1 全量复核，标注真实级别、误报、漏报；独立标注的评测集用于统计未出信号的漏报。
6. **P0 例外**。真实影子阶段的 P0 按获准的值班安排通知工作人员协助，CJ 自身应急指引独立运行。阶段 1–2 告警仅用工作台页内横幅、声音和浏览器通知。

## 边界

- 真实影子阶段只检测、记录、复核，P0 按上节边界协助。真实建单、playbook 执行、揭示、预订、支付、正式旅程和普通主动客户触达留待对应授权。
- 复核角色只见脱敏内容及必要的案件编号。工作台不显示用户 UUID 或内部来源引用。
- 真实存储实际提供时，同 PR 登记并交付清理钩子。信号与标注随用户删除和注销处理。隐私政策及用户说明必须覆盖自动分析、人工复核及可能跨境处理，并取得单独同意。

## 真实阶段验收

| 项目 | 标准 |
| --- | --- |
| P0 召回 | 标注集任一 P0 漏报即失败，逐例复盘 |
| 分类质量 | 各候选用同一标注集分别报告分类精确率和召回率，样本不足标 UNKNOWN |
| 对话影响 | 首 token 延迟 p95 与失败率无可测劣化 |
| 故障隔离 | JT Agent 停掉时 CJ 照常可用；模型不可用时本地规则继续识别 P0 |
| 费用 | 按候选分别记录每千轮费用及未知项 |
| 脱敏 | 回归测试通过，外发抽样中无未替换个人信息 |

## 前置与退出条件

阶段 4 开始前须有 JT 授权、#225 与 #714 前置就绪、真实事件源、同意文案和合规核实，以及值班和复核安排。评测需要外部模型时另行取得具名候选模型的访问和使用授权，并确认数据保留与训练政策，凭据按项目规则管理。

扩大真实处理范围须有 P0 召回达标、主要类别精确率达到 JT 确定的阈值、人工分钟数初估、合规无阻塞，并获得下一阶段授权。
