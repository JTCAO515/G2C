入口为 [B 的构建 48 放行通知](https://github.com/JTCAO515/G2C/issues/1048#issuecomment-7004930477)，现役候选 `59cc874b5e87bd2e0451b81b144ee0bc2b15b6c9`。沿 [#1048 七项原定义](README.md#3-七项基础链路冒烟--basic-chain-smoke) 分中英记录。截图到齐前，七项仍待真机证据。

先记录 JT 的构建、语言、北京时间、截图与可见服务参考号。B 按对应时间和账号最小范围只读核对访问记录（路由、状态、请求号）和同一会话的 CID。发消息项再用原客户端 MID 对齐接收回执、原 RUN、同轮 timeline 正文、相关 Trip 及原账。账号隔离和实际候选版本由 B 核实。问题记录缺参考号时用其他同源原件核对，无法唯一绑定写 UNKNOWN。草稿仅比对真机前后可见状态。

| 项 | 核对原件 | PASS 标准 |
| --- | --- | --- |
| SM01 强退重开 | 强退前／重开截图，旧 CID，原 timeline 页或恢复所用的原接收回执 | 回到已建立的同一对话，原消息与草稿可见，无此次恢复触发的新 MESSAGE |
| SM02 新对话问答 | 发送前后截图，新 CID/MID，接收回执、RUN、原 timeline 正文 | 新 CID 与旧 CID 独立，北京首都问题在正确语言有完整、正确并实际可见的回答 |
| SM03 历史 | 旧、新两条历史记录及打开后截图，原 CID 与已知 timeline 或原回执 | 真机历史分别打开正确的旧、新对话；界面标题与单独的 200 都无法证明绑定 |
| SM04 后台和锁屏返回 | 两次转场的时间、前后截图、恢复原读与 MESSAGE/attempt 差值 | 按原定义分别核后台及锁屏，原对话、已答内容和未发草稿连续，无重复发送或重复欢迎语 |
| SM05 身份 | 原 MID/RUN、可见正文和实际截图 | 对同轮提问用正确语言明确说明 Lio 身份，静态欢迎语不计 |
| SM06 能力 | 原 MID/RUN、已审同源正文、实际截图 | 有具体肯定的可用能力。订票和付款限制允许保留，否认规划、裸标题、引文或欢迎语不计 |
| SM07 三日游 | 原 MID/RUN、完整可见正文或日卡、原 Trip／版本／保存回执（若发生） | 北京第 1、2、3 天都有明确可执行活动及日内时段或顺序，正文可见。裸地点、追问、截断或空卡 FAIL。若宣称保存，须核实同一原动作的正式写入；无日期预览按实际模式核零正式保存 |

同时记录可证的首进度、首正文及完成时间，三栏费用保留保守占用、已知估算、实付。独立记录可见回答、原 RUN、写入和计费，不把完整可见正文因内部格式或费用状态改判为无回答。无正文或缺行程判 FAIL；已执行却缺唯一原件判 UNKNOWN；未执行为 UNRUN。首个产品 FAIL/UNKNOWN 停后续并交对应线，不要求 JT 重发。全过才通知 L。
