# Lio 正文与结果动效（#913 PR3）

本次只调整 CJLioUser 的展示节奏。消息原件、状态机、来源、保存与记忆操作保持原客户端路径；不引入 Textual，不更换 Markdown 解析器，最低系统仍为 iOS 17。

`LioStreamingText` 最短每 40ms 调用现有 `LioReplyMarkdown.render`，只有已经通过该渲染器展示检查的结果才能进入缓冲。尚含字面行内分隔符的流式结果继续保留上次已准入前缀；完成后仍由原渲染器解释全部原文。完整源若被拒绝，立即清掉正文并显示原有提示，不能用安全前缀掩盖拒绝。

`LioStreamingBuffer` 使用原有 Markdown 结果的行与字体信息，标题和列表在行边界封闭后一起追加；中文按完整字符、英文按闭合词追加。累计显示按原字节拼接，跨块组合字符在同一个字素边界展示。大量积压加速，完成事件立即放出已渲染的全部结果，最后一批字在 150ms 内淡入。关闭动效时每 100ms 整块追加，结束立即显示。解析、缓冲和颜色插值都不写入消息或偏好。

计时驱动与文字绘制分离，暂停刷新不冻结静态内容。后台、离屏、菜单覆盖和新对话淡出期间停止正文时钟；再次显示时直接恢复当前已准入内容。展示进展仅在仍是原会话、当前聊天、跟随正文时推动滚动；用户上翻后不抢回位置。首字和正文结束的本机时长来自实际展示回调，仍不保存内容或标识。

新问题的结果卡等待正文展示结束后约 200ms 出现，复用 `LioTheme.Motion.emphasis` 与 98% 起始缩放；只有原先已经存在的已保存行程能进入该路径。新出现的保存勾播放一次系统 bounce，成功触感只触发一次。历史、已经看过的卡片、旧记忆标签不重播；减少动态效果直接显示终态。改动不改变撤销、记忆确认、未知结果和重发条件。

菜单覆盖、新对话淡出或离开聊天时，尚未出现的结果卡暂停揭示，不消耗首次呈现标记或触发成功触感；恢复可见后只呈现一次。`waiting / entering / shown` 三个本地阶段只管理展示，不能代称服务端保存阶段。

兼容停点：#933 的第四版分段渲染器尚未合入当前默认聊天。它暂不调用本文的正文结束回调，因此仅该独立消费者的已保存卡片保持原终态显示规则，防止因缺少展示回调而隐藏实际已保存行程。#933 接入流式回调后移除这条兼容分支；本次不据此认定第四版 Home L1 或香港资格通过。

证据继续按 L0、模拟器 L1、真实服务与 JT L3 分开记录。合成夹具、自动审计和模拟器不代称真机触感或后端完成。
