# 本地协助 v1 使馆目录核对

数据核对日为 2026-11-23。收录[中国外交部外国驻华使馆机构信息](https://www.mfa.gov.cn/web/lbfw_673061/wgzhslgjgxx/)六页中的全部 178 条大使馆条目。驻华代办处不在本版大使馆范围。国家选择使用两字母地区代码及系统中英文地区名。使馆名、办公地址、总机或一般接待电话、官网取自外交部对应详情页。洪都拉斯详情只给出中文地址，英文为该地址的转写。整理时未拨打电话。

## 公开信息缺口

- 摩纳哥和圣马力诺为非常驻条目，两条均无北京办公地址及总机。
- 朝鲜、新加坡、乌克兰详情只列部门联系方式，未列可确认的总机或一般接待号码。
- 外交部条目未提供可核对的坐标。地图精确定位仍待有明确权限的来源，目录中坐标留空。
