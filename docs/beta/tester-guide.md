# Go2China · 构建 52 内测 / Build 52 internal beta

**安装与登录 / Install and sign in**\
收到内部邀请后，在 iPhone 安装 TestFlight，用获邀 Apple 账号接受邀请，安装或更新 Go2China，核对构建号为 52。打开 App，输入单独发给你的短码，阅读并确认内测说明。\
On your iPhone, install TestFlight, accept the internal invitation with the invited Apple Account, and install or update Go2China. Check that it shows build 52. Open the app, enter the code you received privately, and review and accept the beta notice.

短码格式为 `G2C@` 或 `CJ_Tester@` 后接两位半角数字（01–99），区分大小写，不能有空格。构建 52 的千问翻译和滴滴使用内部获配的 `G2C@` 组账号。\
The format is `G2C@` or `CJ_Tester@` followed by two ASCII digits (01–99). Match the capitalization exactly and leave out spaces. Use your assigned internal `G2C@` account for Qwen translation and DiDi in build 52.

**四个 Tab / Four tabs**\
聊天 / Chat 与 Lio 问答和规划；行程 / Trips 查看已保存安排；插件 / Tools 打开翻译和打车；记忆 / Memory 查看已确认的偏好。\
Chat with Lio for answers and plans, open Trips for saved itineraries, use Tools for translation and rides, and see confirmed preferences in Memory.

| 建议试这 8 项 | Try these 8 checks |
| --- | --- |
| 1. 新建对话，问北京首都机场怎么进城，核对回答语言及内容。 | Start a chat. Ask how to get into town from Beijing Capital Airport. Check the answer and its language. |
| 2. 打开一段历史对话，留草稿，切后台或锁屏后返回。 | Open an earlier chat, leave a draft, then check both after backgrounding or locking the phone. |
| 3. 请 Lio 排北京三日游，核对三天内容。若显示已保存，到「行程」查看。 | Ask for three days in Beijing. Check all three days and open it in Trips if the app says it saved. |
| 4. 在「插件 → 翻译」输入一句话，交换中英再试。 | Open Tools → Translation. Translate a sentence, swap Chinese and English, and try again. |
| 5. 中英各录一句，对照识别文字和译文。 | Record a short sentence in each language and compare the transcript with the translation. |
| 6. 拍一张只有示例文字的路牌或菜单，核对识别文字和译文。 | Photograph a sample sign or menu and check the recognized text and translation. |
| 7. 设备支持且已下载语言包时，断网试文字翻译，查看「离线翻译」标记。 | On a supported device with language packs installed, go offline and look for the Offline translation label. |
| 8. 从行程选公开地点或手动输入，打开滴滴链接，核对起点和终点后停止。 | Use public places from a trip or enter them manually. Open DiDi, check pickup and drop-off, then stop. |

**限制 / Limits**\
仅限获准的内部成员，使用合成测试内容。打车只检查链接，进入滴滴后不要下单或付款。52 隐藏酒店入口。最终开放项以 [A 的构建说明](https://github.com/JTCAO515/G2C/issues/702) 为准。\
Use sample data. Testing is for approved internal members only. Check the DiDi link and stop before ordering or paying. Hotels are hidden in build 52. See the [build notes](https://github.com/JTCAO515/G2C/issues/702) for the final scope.

**反馈 / Feedback**\
截图并记下发生时间和时区。从失败提示或菜单中的内测说明打开「问题记录」，点「复制」。通过内测邀请中指定的内部渠道提交，附上构建号、操作、预期和实际结果。请先遮住邀请码、令牌及个人信息。\
Take a screenshot and note the time and time zone. Open Problem notes from the error message or the beta information in the menu, then tap Copy. Send the details through the internal channel named in your invitation, with the build number, steps, and expected and actual results. Remove codes, tokens, and personal data before sending.
