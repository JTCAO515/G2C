## 环境变量名与准备

以下仅为**拟议配置名**，不是已实现代码需要的变量，也不是第三方 SDK 官方变量保证。CJ-005 与领域 owner 初始化时确定最终命名/校验并生成无秘密样例。这里不填任何 key、token、地址或默认生产值。

| 拟议名称 | 所属与用途 | 暴露边界 |
|---|---|---|
| `CJ_ENV`、`CJ_API_BASE_URL` | 环境身份、App 测试 API 地址 | 可公开配置；缺失就失败，不回落旧生产 |
| `SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY` | 候选 Auth 项目地址/公开客户端标识 | 最终采用 SDK 后核名称；公开 key 不代表业务权限 |
| `CJ_DATABASE_URL` | 新业务数据库连接 | 服务端秘密，绝不入 App/日志/仓库 |
| `CJ_AUTH_ISSUER`、`CJ_AUTH_AUDIENCE` | 服务端身份验证预期 | 公开元数据；验证方式与缓存策略待 AUTH 固定 |
| `CJ_MODEL_API_BASE_URL`、`CJ_MODEL_ID`、`CJ_MODEL_API_KEY` | 单主模型端点/ID/凭据 | API key 仅服务端，真实 ID/地域由 CJ-002 核验 |
| `CJ_GAODE_API_KEY`、`CJ_FACT_PROVIDER_API_KEY` | 地点/路线、实际选中事实来源凭据 | 服务端秘密；来源未选不用虚构 key；iOS 地图 SDK 如需独立标识另行登记 |
| `CJ_WORKFLOW_DATABASE_URL`、`CJ_MEMORY_STORAGE_PATH` | 候选持久执行与内部记忆存储 | 服务端；非临时盘，实际要求待 CJ-002/003 验证 |
| `CJ_RUN_MAX_SECONDS`、`CJ_USER_USAGE_LIMIT` | 运行上限与用量准入 | 服务端；数值/计量单位待预算和 USAGE 契约，不写猜测默认值 |

不为未采用供应商创建凭据，不假定需要高权 service-role key。初始化后确认每一变量 owner、必需性、单位、环境、缺失行为和脱敏策略；实际秘密通过官方安全入口交接，不在聊天/文档/样例中填写。
